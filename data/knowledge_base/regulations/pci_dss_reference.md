# PCI DSS reference

This project reference summarizes controls relevant to payment-processing
requirements. It is not the official PCI DSS standard and must not replace a
qualified compliance assessment.

- Protect stored account data with strong encryption or approved protections.
- Restrict access to cardholder data by business need and enforce unique user
  identification and multi-factor authentication for administrative access.
- Log and monitor access to systems and cardholder data, and retain audit
  evidence according to the organization's approved retention policy.
- Apply secure development practices, vulnerability management, and regular
  security testing to payment software.
- Minimize stored cardholder data and never store sensitive authentication data
  after authorization.
