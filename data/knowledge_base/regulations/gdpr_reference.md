# GDPR reference

This project reference summarizes privacy requirements relevant to financial
software. It is not legal advice or the official GDPR text.

- Process personal data lawfully, fairly, and transparently for a defined
  purpose.
- Collect only data that is necessary, keep it accurate, and retain it only as
  long as required.
- Protect personal data with appropriate technical and organizational
  measures, including access controls, encryption, and breach response.
- Support data-subject rights and maintain records of processing decisions.
- Apply privacy by design and by default, including masking or minimizing PII
  before sending data to retrieval or AI services.
